# tree

muestra el arbor de archivos de cualquier directorio

```bash
✖ tree 
.
├── front-end-frameworks
├── README.md
└── sistemas-operativos
    └── linux
        └── commands
            └── tree.md

4 directories, 2 files
```

|atributo| use case             |
|--------|----------------------|
|   -s   |        filesize      |
|   -h   |filesize human redable|
|   -a   |     hidden files     |
|   -d   |   Only directories   |
|  -L 2  |  limit tree deepnes  |
|   -p   |   muestra permisos   |
|   -f   |       full path      |
|   -x   | exclud external files|
