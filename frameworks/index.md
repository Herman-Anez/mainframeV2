## 🚀 Ecosistema JavaScript

| Framework / Herramienta | Descripción |
| :--- | :--- |
| **Node.js** | Entorno de ejecución de JS en el servidor. |
| **React** | Biblioteca para la construcción de interfaces de usuario. |
| **Next.js** | Framework de React para aplicaciones listas para producción. |
| **Vite** | Herramienta de construcción (build tool) ultra rápida. |

> [!TIP]
> Cada framework tiene su propia sub-carpeta con guías de inicio rápido y patrones de diseño recomendados.
