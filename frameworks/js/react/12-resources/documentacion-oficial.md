# 🌍 Documentación Oficial y Guías de Referencia

A continuación, se presentan los enlaces oficiales a la documentación de React y las librerías más importantes de su ecosistema.

---

## ⚛️ El Núcleo de React

*   **[React.dev](https://react.dev/)**: El sitio oficial con la documentación moderna de React (basada íntegramente en Hooks).
*   **[Documentación Legacy](https://legacy.reactjs.org/)**: Documentación antigua útil para entender componentes de clase y patrones antiguos.
*   **[Blog de React](https://react.dev/blog)**: Anuncios oficiales, nuevas versiones (como React 19) y cambios en la arquitectura.

---

## 🛠️ Herramientas y Ecosistema

*   **[React Router](https://reactrouter.com/)**: El estándar para navegación y enrutamiento en el cliente.
*   **[TanStack Query](https://tanstack.com/query/latest)**: La mejor solución para la gestión del estado del servidor y caché de datos.
*   **[Zustand](https://zustand-demo.pmnd.rs/)**: Una librería de gestión de estado global pequeña, rápida y escalable.
*   **[Redux Toolkit](https://redux-toolkit.js.org/)**: El conjunto de herramientas oficial y recomendado para usar Redux.

---

## 🎨 Estilos y UI

*   **[Tailwind CSS](https://tailwindcss.com/docs/)**: Framework de CSS basado en utilidades.
*   **[Styled Components](https://styled-components.com/docs)**: Referencia para CSS-in-JS.
*   **[framer-motion](https://www.framer.com/motion/)**: La librería definitiva para animaciones en React.

---

## 🧪 Testing

*   **[Jest](https://jestjs.io/)**: Framework de pruebas principal.
*   **[React Testing Library](https://testing-library.com/docs/react-testing-library/intro/)**: Documentación oficial para testeo centrado en el usuario.
