# Explicación rápida

```tsx
for f in *.md; do
  sed -i 's|\[back](../index.md)|[back](../../README.md)|g' "$f"
done
```

- `for f in *.md; do`
  - Recorre todos los archivos .md.
- `sed -i`
  - Edita el archivo en sitio (sin crear uno nuevo).
- `'s|...|...|g'`
  - Es la sintaxis de sustitución:
    - `s`: sustituir
    - `|`: separador (uso | en vez de / para no escapar las rutas)
    - `\[back](../index.md)`: texto original (los [] se escapan porque son especiales)
    - `[back](../../README.md)`: texto nuevo
    - g: reemplazar todas las apariciones en el archivo
- "$f"
  - El archivo actual.
