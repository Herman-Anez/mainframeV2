# Módulo 04: CI/CD & DevOps

Como SDET, no solo ejecutas pruebas, sino que las integras en ciclos automáticos de entrega continua. Aquí verás el control de versiones avanzado, la construcción de pipelines robustos, la contenerización de entornos de prueba y la orquestación en Kubernetes; todo con un enfoque práctico y específico para testing.

## Estructura del Módulo

### 1. [Git para SDET](./Git/index.md)
Control de versiones avanzado, estrategias de branching y gestión de submódulos para suites de pruebas.

### 2. [Jenkins para SDET](./Jenkins/index.md)
Orquestación de pipelines declarativos, gestión de agentes y notificaciones en tiempo real.

### 3. [GitHub Actions](./GitHub-Actions/index.md)
Automatización nativa en GitHub, workflows reusables y estrategias de matrix testing.

### 4. [Docker para Testing](./Docker/index.md)
Contenerización de entornos, Dockerfiles optimizados para pruebas y Selenium Grid con Docker.

### 5. [Kubernetes y Pruebas](./Kubernetes/index.md)
Orquestación a escala, pods efímeros para pruebas y entornos de testing bajo demanda.
