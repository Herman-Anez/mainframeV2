# Docker para entornos de prueba

Docker proporciona entornos ligeros, aislados e idénticos tanto en desarrollo como en CI y producción. Para un SDET, Docker resuelve el problema de la inconsistencia entre entornos ("en mi máquina funciona") y permite una escalabilidad masiva de las suites de prueba.
