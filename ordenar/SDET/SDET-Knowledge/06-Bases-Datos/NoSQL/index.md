# NoSQL (Bases de Datos Documentales)

Las bases de datos NoSQL, como MongoDB, almacenan documentos en lugar de filas. Las pruebas para estos sistemas requieren validar colecciones y agregaciones complejas que suelen ser fundamentales para la lógica de lectura de la aplicación (reportes, feeds, dashboards).
