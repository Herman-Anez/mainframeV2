# Bases de Datos para SDET

La interacción con bases de datos es una habilidad fundamental para un SDET. No se trata solo de consultar datos, sino de validar la integridad, el rendimiento y la persistencia de la lógica de negocio directamente en la capa de datos.

## Temas del Módulo

### 1. [SQL (Relacionales)](./SQL/index.md)
Consultas avanzadas, procedimientos almacenados e integridad referencial en bases de datos relacionales como PostgreSQL, MySQL y Oracle.

### 2. [NoSQL (Documentales)](./NoSQL/index.md)
Validación de documentos, agregaciones complejas y esquemas dinámicos en bases de datos como MongoDB.

### 3. [Seeds y Fixtures](./Seeds-fixtures/index.md)
Estrategias para la generación de datos de prueba, fábricas de datos y gestión de migraciones para entornos de testing.
